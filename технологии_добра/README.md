# Сбор информации об участниках проекта "Технологии добра"

## Описание

Набор скриптов для автоматического сбора информации об участниках проекта "Технологии добра" с сайта https://xn--80abfedtavrkbe1aq0c.xn--p1ai/

## Что собирается

### Базовая информация (из API):
- ID участника
- Название организации
- Регион присутствия
- Сайт организации
- URL логотипа

### Детальная информация (с сайтов):
- Email адреса
- Телефоны
- Описание деятельности
- Социальные сети (VK, Telegram, Facebook, Instagram, YouTube)

## Структура проекта

```
collect_participants.py     - Сбор базовой информации через API
collect_details.py          - Сбор детальной информации с сайтов
create_report.py            - Создание Excel/CSV отчетов
participants.json           - Базовые данные всех участников
participants.csv            - То же самое в CSV формате
participants_detailed.json  - Детальная информация (если собрана)
participants_report_*.xlsx  - Финальный отчет в Excel
participants_report_*.csv   - Финальный отчет в CSV
```

## Использование

### 1. Сбор базовой информации

Загрузка всех участников через API (быстро, ~5 секунд):

```bash
python collect_participants.py
```

**Результат:** 
- `participants.json` - 1573 участника в JSON формате
- `participants.csv` - те же данные в CSV

### 2. Сбор детальной информации с сайтов

#### Тестовый режим (первые N участников):

```bash
python collect_details.py 20
```

#### Полный сбор всех участников с сайтами:

```bash
python collect_details.py
```

**Внимание:** 
- Обработка 737 участников с сайтами займет ~15-20 минут
- Промежуточные результаты сохраняются каждые 10 участников
- Можно прервать и продолжить позже

**Результат:**
- `participants_detailed.json` - детальная информация

### 3. Создание отчета

Создание Excel и CSV отчетов:

```bash
python create_report.py
```

**Результат:**
- `participants_report_YYYYMMDD_HHMMSS.xlsx` - Excel отчет
- `participants_report_YYYYMMDD_HHMMSS.csv` - CSV отчет

## Примечания

1. **Кодировка Windows:** Используйте PowerShell с правильной кодировкой:
   ```powershell
   $env:PYTHONIOENCODING="utf-8" ; python script_name.py
   ```

2. **Ограничения API:** Сервер может временно заблокировать при слишком частых запросах. 
   В скрипте используются задержки (0.5-1 сек между запросами).

3. **Качество данных:** Некоторые сайты могут быть недоступны или иметь нестандартную структуру.
   Скрипт продолжит работу и сохранит ошибку в отчете.
